## Создание ZIP в Windows

Выполните из корня проекта в PowerShell. Команда использует пофайловый перечень и упаковывает относительные пути. При повторном запуске tar перезапишет одноимённый архив.

```powershell
tar.exe -a -cf ProductMind-1.1-2026-11-22.zip -T docs/SUBMISSION_FILES.txt
```

Просмотр состава и проверка после распаковки:

```powershell
tar.exe -tf ProductMind-1.1-2026-11-22.zip
```

Распакуйте в новую папку, установите зависимости по README и запустите команды ниже из её корня. Ожидаются код выхода 0, две версии в demo, семь успешных тестов, base 1 у оператора и две записи в истории копии.

```powershell
.\run.cmd demo
.\run.cmd test
.\run.cmd --project projects/youth-retention context
.\run.cmd --project projects/youth-retention/recovery-test history
.\run.cmd --project projects/youth-retention-v11 context
```
