# Чек-лист записи ProductMind v1.1

**Цель монтажа — 9:00 вместе с титром. Предельная длительность — 10:00. Срок сдачи — 22 ноября 2026 года, 20:00 по Москве.** Все запросы и точные команды собраны в [карточках оператора](DEMO_SCRIPT.md#карточки-оператора).

## Перед записью

- [ ] Открыть корень ProductMind в VS Code. Проверить вход в Codex и доступность соединения. Подготовить два пустых чата и PowerShell в корне. Убрать уведомления, личные вкладки и путь профиля из кадра.
- [ ] Выполнить блок «Подготовка терминала». Проверить результат `context` на временной копии: версия 2, три источника. Скопировать фактический путь вместо маркера во втором запросе.
- [ ] Выполнить блок «История» в том же терминале. Видны две версии с основаниями 0 и 1. Выполнить `.\run.cmd test`, проверить семь тестов и строку `OK`.
- [ ] Открыть вкладки в порядке показа: `projects/youth-retention/BRIEF.md` → `README.md` → `projects/youth-retention-v11/DECISIONS.md` → первый чат → `REPORT.md` → `EXPORT-NOTE-A.txt` и `EXPORT-NOTE-B.txt` → история и второй чат → `docs/ARCHITECTURE.md` → тесты → `evaluations/quality-checklist.md` → `STATE.md`. Имена без каталога в этой последовательности относятся к youth-retention-v11.
- [ ] Записать резервные дубли обоих чатов с отправкой запроса и ответом. Для первого использовать только исходный бриф. Для второго сверить версию, стратегию, шаг и ссылки S2/S3. Пометить границу между свежим ответом и сохранённым прогоном.
- [ ] Сделать пробную запись окна VS Code в 1920 × 1080, 30 кадров/с. Увеличить шрифт, проверить перенос строк и крупные планы обеих половин матрицы. Включить запись микрофона, прослушать фразу в наушниках, проверить окончания слов и отсутствие перегруза.

## Запись и экспорт

- [ ] Провести прогон с секундомером. Контрольные входы — 1:30 диагностика, 3:00 матрица, 4:30 конфликт, 6:00 память, 7:15 техника, 8:15 итог. При отставании сократить ожидание и навигацию. В записи сохранить подлинную отправку запроса.
- [ ] Показать маркировку синтетических материалов, одинаковые выгрузку и редакцию в строках 2, сохранение стратегии и смену ближайшего шага. На переходах подписать предыдущий прогон и сокращённое ожидание.
- [ ] Просмотреть экспорт целиком в обычном проигрывателе. Проверить длительность от первого кадра до последнего, разборчивость русской речи, синхронность выделений, читаемость источников и результата тестов. Убедиться, что в ролик попал подлинный запуск Codex.
