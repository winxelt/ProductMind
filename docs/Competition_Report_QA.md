## Редактирование и сборка

Текст и таблицы находятся в ProductMind_Competition_Report.md. Строки с !architecture, !gap, !web и !manager обозначают места для схемы, диаграммы и снимков. Для сборки из корня проекта выполнить в Python со средствами подготовки отчёта:

    python docs/build_competition_report.py

Сборка использует ReportLab и Pillow; доступные шрифты — Segoe UI либо DejaVu Sans. Для проверки использованы pypdf, pdfplumber и pypdfium2. При подготовке документа новые зависимости не устанавливались. Источник снимков — открытые в VS Code файлы projects/megafon-official-hitl/WEB_RESEARCH.md и DECISION_V2.md. Это снимки документации проекта, а не интерфейсов операторов и не переписки с руководителем.

Исторические значения 1,231 с и 0,182 с на странице 11 взяты из протокола HITL_TESTING.md и относятся к первоначальной проверке контрольной точки. В этой подготовке повторно проверялись документы, тесты и восстановление. Пилот не запускался. Время всей работы, токены и стоимость работы Codex не измерены. Дополнительные скриншоты для описанных в задании требований не нужны.
