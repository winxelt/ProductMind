# Проверка Strategic Decision Engine v1.1

21 ноября 2026 года. Тестируемое изменение — правила, по которым Codex диагностирует проблему, сравнивает варианты и оформляет решение. CLI и схема журнала общие с 1.0.

| Проверка | Выполнено и наблюдалось |
| --- | --- |
| Старые проекты | Отдельные вызовы context и history прочитали pilot (2 версии), youth-retention (1), recovery-test (2). Последняя запись совпала с состоянием каждого проекта. |
| Вход в новую версию | В отдельную папку скопирован закрытый основной журнал оператора. context вернул базовую версию 1 и S1. Через add импортированы два синтетических условия, получены S2 и S3. |
| Разбор и сохранение | Codex прочитал условия, сравнил варианты и подготовил REPORT.md. Команда save с базой 1 и источниками 1, 2, 3 вернула версию 2. В новых процессах context и history прочитали её полный текст. Сверены ссылки, предшествующая версия и совпадение отчёта с файлом. Первая запись копии равна исходной записи 1.0 по всем полям. |
| Проверка формы | В сохранённом отчёте программно проверены четыре отдельных вопроса, три строки по шести критериям, указанный уровень уверенности, ссылки на две спорные строки и три строки условий пересмотра с четырьмя полями. |
| Проверка по смыслу | У вопросов есть ответы, меняющие следующий шаг. Отсутствие игровой мотивации обозначено как гипотеза. Для обеих схем выгрузки разобраны последствия. Спор остался открытым. В выборе учтены слабые основания и неизвестная цена. Развитие и закрытие имеют разные условия перехода и разные эксперименты. |
| Регрессия | Запущен весь исходный набор через run.cmd test. Семь тестов прошли, ошибок и пропусков нет. |
| Сохранность | До и после прогона совпали SHA-256 трёх старых журналов, прежнего TESTING.md, архива 1.0, CLI, запускателя и файла тестов. |

## Как прочитать результат

```powershell
.\run.cmd --project projects/youth-retention-v11 context
.\run.cmd --project projects/youth-retention-v11 history
.\run.cmd test
```

В версии решения 1 был вывод о необходимости диагностики и таблица альтернатив. В версии 2 стали явными объём и качество свидетельств по каждому варианту, цена отмены, скорость получения знаний и уверенность в общем выборе. Уточнения связаны с решениями, конфликт ссылается на обе исходные строки.

Один подготовленный учебный прогон подтверждает выполнение процедуры на этом кейсе. Содержательную оценку провёл Codex, который составлял отчёт. Независимая экспертиза качества рекомендаций, измерение пользы на реальных пользователях и статистическая калибровка уверенности не проводились. Матрица и условия пересмотра хранятся в тексте отчёта. CLI не навязывает их при ручном save.
