# Реестр источников

Подробный реестр демонстрационного проекта. Сейчас строк нет: исследования не проводились, ссылки и компании не добавлены.

В реестр попадает только материал, который действительно открыли. Поисковый сниппет, неоткрытая ссылка и пересказ без оригинала сюда не записывают как подтверждение. Оценка строки идёт по `knowledge/source-quality.md`.

Краткая сводка фактов остаётся в `STATE.md` и должна совпадать с этим реестром. Этот файл не заменяет файл состояния.

## Поля

| Поле | Что писать |
| --- | --- |
| ID | Короткий код строки, например S1. Код не переиспользуют |
| Название | Название материала, как оно указано в самом материале |
| URL или путь к файлу | Ссылка или путь к переданному файлу. Если пути нет, напиши «не указан» |
| Автор | Автор или организация из материала. Если автора нет, напиши «не указан». Не выдумывай |
| Дата публикации | Дата в материале или «дата не указана» |
| Дата обращения | Когда материал открыли |
| Тип источника | Например: бриф, таблица, интервью, официальный документ, статья, пересказ |
| Какие утверждения подтверждает | Номера или короткие формулировки утверждений, и не шире самого текста |
| Ограничения | Границы источника: выборка, период, зависимость, неполный текст |
